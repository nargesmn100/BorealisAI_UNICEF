## KNOWN LIMITATIONS (document, do not fix)

These are research limitations to be clearly stated in any presentation
or report. They are not bugs.

L1  No fine-resolution ground truth exists for Jamaica at grid level.
    Evaluation metrics measure proxy agreement (vs -RWI), not true accuracy.

L2  Only 3 administrative zones for reconciliation (Urban/Rural/KMA).
    Within each zone, all ML redistribution is unconstrained.

L3  The 1,745 RWI grid cells are sparsely spaced (~2 km apart on average).
    Fine-scale features (100m population raster) are point-sampled, not
    aggregated -- some signal is lost.

L4  The RWI data is derived from Meta's Connectivity Lab model (2019-2021).
    It may not reflect 2022 conditions used in the poverty targets.

L5  Confidence intervals for reconciled predictions are approximate.
    Interval widths are computed on raw scores and shrink/grow when
    reconciliation rescales predictions to match admin totals.

L6  The model is trained and evaluated on the same small dataset
    (all cells with non-null targets). No hold-out validation is possible
    without withheld admin zones.
